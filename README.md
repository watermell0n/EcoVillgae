# 이코빌리지 MVP

- 기준일: 2026-07-28
- 상태: 회의 후 MVP 방향 정리
- 대상: 초등학교 4~6학년

> 이 README는 현재 만들 MVP의 목표와 범위만 설명합니다. MVP 이후 추가 모듈과 장기 발전 방향은 [추가 모듈 및 발전 방향](docs/FUTURE_MODULES_AND_ROADMAP.md), 아직 결정하지 않은 사항은 [미확정 이슈](docs/OPEN_ISSUES.md)에서 관리합니다.

## 1. 제품 한 문장

교사가 학년과 운영기간에 맞는 코스와 모듈을 선택하면, 학생이 학교 태블릿으로 자율시간과 교사 지도 활동에서 지속적인 학급 경제를 경험하는 교육 플랫폼입니다.

## 2. 이번 회의에서 확정한 MVP 기준

- MVP 대상은 **초등학교 4~6학년**입니다.
- 중학생용 코스는 MVP에서 제외합니다.
- 코스 기간은 **1회, 1주, 1달, 1학기** 네 종류입니다.
- 시스템은 학년과 기간을 함께 고려해 적합한 코스와 모듈 조합을 추천합니다.
- 코스 추천은 AI가 즉석에서 만드는 방식이 아니라 팀이 검증한 추천표를 사용합니다.
- 퀴즈 생성·관리는 교사에게만 보입니다.
- 학생에게 제공할 퀴즈 콘텐츠는 우선 **경제 퀴즈와 넌센스 퀴즈**로 구성합니다.
- AI 경제 밸런싱, 교사용 AI 챗봇, AI 경제 이벤트 생성을 MVP 우선 기능으로 둡니다.
- 자리·부동산 모듈은 MVP에 포함하지 않습니다.

## 3. 이용 환경과 화면

| 사용자·화면 | 주요 역할 |
| --- | --- |
| 교사 운영 웹 | 경제교실 개설, 코스·모듈·정책 설정, 자율시간 관리, 퀴즈 생성, AI 운영 지원, 거래 승인, 리포트 확인 |
| 학생 태블릿 화면 | 지갑, 상점, 캐릭터, 개인거래, 예금, 퀴즈·투표 참여와 개인 기록 확인 |
| 교실 공용 화면 | 문제, 타이머, 익명 집계, 활동 진행상태와 공개 가능한 결과 표시 |

- 학생은 학교에서 지급한 개인 태블릿을 사용합니다.
- 점심시간, 쉬는시간과 자유시간에는 교사가 허용한 모듈만 자율적으로 이용할 수 있습니다.
- 퀴즈와 투표처럼 함께 진행하는 활동은 교사가 시작합니다.
- 지도 활동이 시작되면 학생 화면은 교사 화면을 복사하지 않고 같은 활동의 학생용 화면으로 이동합니다.
- 학생의 잔액, 세금, 평가 결과와 개인 기록은 다른 학생이나 공용 화면에 공개하지 않습니다.

## 4. 코스 추천 방식

코스는 고정 진도가 아니라 경제교실을 빠르게 시작하기 위한 추천 템플릿입니다. 추천 결과를 본 뒤 교사가 실제 모듈과 일정을 수정할 수 있습니다.

### 4.1 학년별 중점

| 학년 | 추천 학습 중점 |
| --- | --- |
| 초4 | 돈 받기, 지갑과 거래기록, 소비 선택, 남은 돈 확인, 예산과 저축 목표 |
| 초5 | 월급명세서, 세금, 상점, 예금, 학급 공공기금 |
| 초6 | 세금, 가격 변화, 물가의 기초, 공공예산과 복지의 기초 |

### 4.2 기간별 깊이

| 기간 | 추천 운영 방식 |
| --- | --- |
| 1회 | 지갑 → 소득 → 세금·명세서 → 소비 → 남은 돈과 선택 이유 확인 |
| 1주 | 첫 경제활동 → 중간 자율활동·퀴즈 → 마지막 예금 결과·공공기금 투표·리포트 |
| 1달 | 월급·세금·소비·예금 사이클을 반복하고 학년별 중점 활동과 AI 경제 이벤트를 추가 |
| 1학기 | 장기 자율운영, 반복 경제 사이클, 공공의사결정과 누적 자산·학습 리포트 운영 |

### 4.3 추천 계산 원칙

1. 교사가 학년과 기간을 선택합니다.
2. 시스템이 `학년별 중점 × 기간별 깊이`에 맞는 검증된 모듈 묶음을 추천합니다.
3. 기술적으로 필요한 기반 모듈은 함께 표시합니다.
4. 교사가 추천 이유를 확인하고 모듈을 추가하거나 제외합니다.
5. 선택하지 않은 모듈은 학생 화면에서 숨깁니다.

AI 코스 설계와 기존 코스 자동 재구성은 MVP에서 사용하지 않습니다.

## 5. MVP 기능 범위

### 5.1 공통 기반

- 교사·학생 계정과 경제교실
- 출석번호·닉네임·비밀번호 기반 학생 로그인
- 학교 태블릿 연결
- 지갑과 수정하지 않는 거래 원장
- 자율 이용시간과 교사 지도 활동 제어
- 교실 공용 화면
- 알림, 감사 기록과 기본 리포트

### 5.2 학생 경제활동

- 월급명세서, 역할별 월급과 소득세
- 공식 디지털 상점과 실제 상품 상점
- 상품별 부가세
- 캐릭터와 꾸미기용 디지털 아이템
- 학생 간 상대 지정 개인거래와 교사 승인
- 개인거래 부가세
- 정기예금
- 학급 공공기금, 예산과 익명 투표

### 5.3 퀴즈

- 퀴즈 생성·문제은행·수정·승인은 교사용 웹에만 표시합니다.
- 학생은 교사가 공개하거나 시작한 퀴즈에만 참여합니다.
- 초기 콘텐츠 분류는 경제 퀴즈와 넌센스 퀴즈입니다.
- AI를 사용한 문제 생성은 초안 생성으로 제한하고 교사 승인 후 사용합니다.
- 게임 결과에는 1~3위의 닉네임과 캐릭터만 공개할 수 있습니다.
- 속도는 게임 점수에 반영하되 화폐 속도 보상에는 상한을 둡니다.

퀴즈의 게임형·평가형 운영 범위는 [미확정 이슈](docs/OPEN_ISSUES.md)에서 최종 확정합니다.

## 6. MVP 우선 AI 기능

세 기능은 교사용 **AI 학급 경제 운영 지원**으로 연결하되 내부 책임은 분리합니다.

### 6.1 AI 경제 밸런싱

- 학급의 화폐량, 소비율, 상품 판매 속도, 재고와 자산 집중도를 집계합니다.
- 화폐 과잉, 조기 품절, 소비 정체와 자산 집중 위험을 감지합니다.
- 가격, 재고와 활동 보상에 대해 단일 정답이 아닌 안전한 조정 범위를 제안합니다.
- 변경 전후의 예상 효과와 부작용을 시뮬레이션합니다.
- AI가 값을 직접 적용하지 않고 교사가 설정 화면에서 결정합니다.

### 6.2 교사용 AI 챗봇

- 현재 학급 경제 상태와 변화 이유를 설명합니다.
- 경고가 발생하기 전에도 교사가 예상 위험과 조정 범위를 질문할 수 있습니다.
- 근거 지표, 가능한 원인과 대안별 예상 영향을 함께 보여줍니다.
- 읽기·상담 중심이며 코스, 설정, 학생 잔액과 계좌를 직접 변경하지 않습니다.

### 6.3 AI 경제 이벤트 생성

- 현재 경제 상태와 학습 목표에 맞는 이벤트 초안을 교사에게 제안합니다.
- 검증된 이벤트 템플릿 안에서 이야기, 선택지, 진행 문구를 생성합니다.
- 금액, 확률, 가격 변화와 실제 효과는 규칙 엔진과 시뮬레이터가 계산합니다.
- 교사 승인 전에는 학생에게 공개하거나 실행하지 않습니다.
- 이벤트의 운영 효과와 학습 효과를 구분해 보여줍니다.

### 6.4 AI 공통 원칙

- 시스템이 지표와 금액을 계산하고 AI는 설명과 선택지를 만듭니다.
- 모든 AI 결과는 구조화된 형식과 안전 검증을 통과해야 합니다.
- 교사 승인 없이 AI 결과를 공개하거나 설정에 반영하지 않습니다.
- AI가 데이터베이스와 학생 계좌를 직접 수정하지 않습니다.
- 학생 데이터는 필요한 최소 범위만 가명화해 사용합니다.
- 실제 금융상품, 실제 종목 추천과 가격 예측은 제공하지 않습니다.

## 7. 핵심 거래 원칙

- 모든 금액 변경은 거래 원장을 통해서만 처리합니다.
- 완료된 거래는 수정·삭제하지 않습니다.
- 운영 오류는 원거래를 참조하는 복구 거래로 정정합니다.
- 정책 변경은 이후 거래부터 적용하고 과거 거래에는 당시 정책을 남깁니다.
- 잔액 부족, 재고 부족 또는 중복 요청 시 거래 일부만 처리하지 않습니다.
- 개인거래는 `A의 제안 → B의 동의 → 교사 승인 → 금액·세금·아이템 동시 이전` 순서로 처리합니다.
- 정상 완료한 상품 구매와 개인거래에는 학생 환불 기능을 제공하지 않습니다.

## 8. MVP에서 제외하는 범위

- 자리·부동산 모듈
- 중학생용 코스
- 적금, 주식투자, 보험, 대출·신용
- 학생 운영 상점의 생산·재고·매출·이익
- 주거·청약
- 학생용 자유대화 AI, AI 역할극과 장기 개인화 추천
- 실제 금융상품과 실제 종목을 이용한 투자 기능

제외 기능은 삭제된 아이디어가 아니라 MVP 검증 이후 검토할 후보입니다.
