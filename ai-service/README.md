# AI 서비스

Python, FastAPI와 Pydantic을 사용하는 AI 작업 영역입니다.

## 소유 범위

- 경제 상태 지표 입력과 밸런싱 제안
- 교사용 읽기 전용 챗봇
- 경제 이벤트와 퀴즈 초안 생성
- Bedrock 기본 어댑터와 OpenAI 보조 어댑터
- 구조화 응답 검증과 회귀 평가

## 경계

- 학생 원본 데이터와 실명 정보를 직접 조회하지 않습니다.
- 데이터베이스·학생 계좌·경제 정책을 직접 변경하지 않습니다.
- 금액·확률·경제 효과는 핵심 API의 규칙 엔진이 결정합니다.
- AI 결과는 교사 승인 전 학생에게 공개하거나 적용하지 않습니다.

초기 FastAPI 프로젝트는 이 디렉터리 안에서만 생성합니다.
