# 캐릭터·프로필 에셋

캐릭터 원본과 앱 전달용 에셋의 공통 작업 영역입니다.

권장 하위 구조:

```text
source/     편집 가능한 원본과 제작 증적
exports/    앱·웹에서 사용하는 최적화 결과
preview/    검토용 조합 이미지
```

파일명은 영문 소문자와 하이픈을 사용하고, 슬롯·레이어·크기·포맷은 Jira
`S15P11B201-115`, `S15P11B201-116`에서 먼저 확정합니다. 퍼블릭 도메인 캐릭터를
사용하더라도 배포 지역의 저작권·상표·2차 저작물 검토 증적을 함께 보관합니다.
