# 이코빌리지 AI 활용 방향

- 확정일: 2026-07-30
- 상태: MVP AI 범위·책임·기술 확정

## 1. MVP 우선순위

1. AI 경제 설정 추천·시작 전 점검
2. AI 경제 자동 모니터링·밸런싱
3. 교사용 AI 챗봇
4. AI 경제 이벤트 생성
5. 교사용 AI 퀴즈 초안 생성

AI 코스 자동 생성, 학생용 자유대화, 역할극 NPC와 장기 개인화는 MVP에서 제외합니다.

## 2. 책임 분리

| 책임 | 담당 |
| --- | --- |
| 지표·금액·허용 범위·거래 결과 계산 | Spring 핵심 API와 규칙 엔진 |
| 설명·요약·이벤트 이야기·선택지·퀴즈 초안 | AI 모듈 |
| 공개·적용·수정·거절 | 교사 |

## 3. AI 경제 설정 추천·밸런싱

### 3.1 설정 과정의 추천

추천은 수업 시작 직전에 한꺼번에 생성하지 않고 교사의 설정 흐름에 맞춰 제공합니다.

| 시점 | 우선 추천값 | 주요 입력 |
| --- | --- | --- |
| 경제교실 개설 마법사의 마지막 설정 단계 | 수치 후보 없음, 공통 필수값만 점검 | 학년, 예상 학생 수, 실제 운영기간, 통화명, 선택 모듈 |
| 역할·급여·소득세·예금·대출 모듈 활성화 | 활성화할 모듈의 급여·세율·신규 예금금리·신규 대출금리 | 학년, 실제 운영기간, 지급 일정, 현재 활성 모듈·관련 정책 |
| 상품 등록·수정 | 상품 가격 | 현재 급여·세율, 상품 유형·재고, 예상 구매 빈도 |
| 퀴즈 등록·세션 설정 | GAME 보상 | 퀴즈 유형·문항 수·참여 방식, 급여와 현재 구매력 |

- `TEST`에는 화폐 보상을 추천하지 않습니다. 코스 라벨만으로 보상을 금지하지 않고 실제 활성 모듈과 발행 예산을 사용합니다.
- Spring 규칙 엔진이 추천값·허용 범위·근거 코드를 계산하고 AI는 그 의미와 주의점을 설명합니다.
- AI가 꺼져 있거나 모델 호출이 실패해도 규칙 기반 추천값과 검증 결과는 사용할 수 있어야 합니다.
- 교사는 추천값을 적용·수정·건너뛸 수 있으며, 저장과 실제 정책 반영은 기존 핵심 API가 다시 검증합니다.
- 추천 수락·수정·건너뛰기는 이후 추천 품질을 평가할 수 있도록 기록하되 자동 학습에는 사용하지 않습니다.

### 3.2 첫 경제활동 전 점검

경제교실은 생성 즉시 `ACTIVE`이므로 별도 준비 상태를 추가하지 않습니다. 대신 학생 앱을
처음 `CLOSED → AUTONOMOUS`로 열거나 화폐를 변경하는 첫 지도 활동을 시작하기 전에
최종 점검을 실행합니다.

- 선택한 모듈의 필수 정책 누락·허용 범위 위반은 `BLOCK`으로 처리하고 해당 모듈 활성화나 관련 활동 시작을 막습니다.
- 발행·회수 규모 불균형과 권장 범위 이탈은 `WARN`으로 표시하며 교사가 확인 후 진행할 수 있습니다.
- 급여·세율·금리, 학생 수, 실제 운영기간·지급 일정, 활성 모듈, 상품 가격 또는 퀴즈 보상이 바뀌면 점검 결과를 만료시키고 다시 검사합니다.
- 선택한 경제 모듈이 없는 코스는 경제 점검 대상이 아닙니다. 역할·급여를 선택하지 않은 학생은 직업 없이 정상 이용합니다.
- 시작 전 점검은 미래 경제를 예측하지 않고 현재 설정의 정합성과 정적 예산 범위만 검사합니다.

### 3.3 운영 중 입력 지표

- 화폐 공급 증가율과 회수율
- 평균·중앙 잔액과 자산 집중도
- 소비율, 상품 판매 속도와 재고 위험
- 예금·적금·투자·대출 참여와 결과 분포
- 활동·퀴즈 보상이 화폐 증가에서 차지하는 비율

학생 5명 미만 또는 관련 거래 10건 미만이면 `데이터 부족`으로 처리합니다. 한 번의 이상값이 아니라 연속된 두 분석 구간에서 임계치를 넘을 때 경고합니다.

### 3.4 자동 모니터링과 알림

- 1주 이상 코스는 학급 AI 설정의 동일 길이·비중첩 분석 구간마다 Spring 작업자가 자동 집계합니다. MVP 기본 구간은 7일입니다.
- `NORMAL`은 모델을 호출하지 않고 실행 요약만 저장합니다.
- `OBSERVE`와 `WARN`에서만 AI 설명·조정 제안 후보를 생성하며 자동 적용하지 않습니다.
- 알림은 `NORMAL·OBSERVE·WARN`으로 구분하고 학급·지표·방향·심각도가 같은 알림은 같은 분석 구간에 한 번만 만듭니다.
- 악화, 회복 또는 다음 분석 구간의 재발일 때만 새 알림을 만들고, 교사가 확인한 알림은 현재 구간에서 반복 노출하지 않습니다.
- 모든 자동 실행에는 분석 구간, 데이터 시각, 지표·임계값 버전과 트리거 `AUTO_MONITOR`를 기록합니다.

### 3.5 조정 제안

- 상품 가격과 재고
- 활동·게임 보상
- 소득세·부가세·개인거래세
- 공식 상점 상품군의 물가 조정률
- 신규 예금·적금·대출 금리

교사 승인 후 시스템이 적용하며 세율은 이후 거래, 금리는 신규 금융상품부터 적용합니다. 기존 계좌와 대출은 당시 정책 스냅샷을 유지합니다.

## 4. 교사용 AI 챗봇

- 학급 설정과 활성 모듈
- 화폐·상점·금융상품·퀴즈의 학급 집계
- AI 이벤트와 정책 변경 이력
- 근거 지표, 조회 기간, 데이터 시각, 원인, 대응안과 부작용

MVP에서는 학생 개인 분석을 제외합니다. 비밀번호·토큰·학생 실명·개인 대화·개인 금융정보를 AI 입력에 포함하지 않습니다.

- 질문·답변 원문: 생성 후 30일
- 모델·프롬프트 버전·비용·성공·실패 메타데이터: AI 실행 후 1년
- 교사당 하루 30회
- 응답 제한시간 20초
- 자동 재시도 최대 1회

## 5. AI 경제 이벤트

| 템플릿 코드 | 의미 | 학년 |
| --- | --- | --- |
| `PRICE` | 물가 변동 | 초4~초6 |
| `SUPPLY` | 공급 변화 | 초4~초6 |
| `PUBLIC_FUND` | 공동기금 | 초4~초6 |
| `TAX` | 세금 | 초5~초6 |
| `INTEREST_RATE` | 예금·적금 금리, 초6은 대출금리 포함 | 초5~초6 |
| `INVESTMENT_NEWS` | 가상 투자 뉴스 | 초6 |
| `REWARD` | 전체 보상 조정 | 초6 |

- 1회 코스에는 기본 추천하지 않지만, 교사가 관련 모듈을 선택하고 실제 일정·정책이
  유효하면 사용할 수 있습니다.
- AI는 이야기·선택지·진행 문구만 만듭니다.
- 효과 수치는 검증된 템플릿과 시뮬레이터가 결정합니다.
- 특정 학생 대상 손익, 강제 대출, 개인 잔액 직접 차감과 음수 잔액을 금지합니다.
- 교사 승인 전에는 실행하지 않습니다.
- 초안 생성은 `API-AI-004`, 승인·거절은 `API-AI-006`으로 분리합니다.
- 이벤트 진입 경로는 `MONITOR_RECOMMENDATION`과 `TEACHER_REQUEST`를 모두 허용합니다.
- 자동 모니터링은 템플릿과 근거만 추천하며 교사가 선택한 뒤에만 전체 이벤트 초안을 생성합니다.
- 같은 분석 구간의 같은 근거·템플릿 추천은 중복 생성하지 않습니다.

## 6. AI 퀴즈

- 교사가 학년, 난이도, 개념, 경제·넌센스 분류와 학습목표를 입력합니다.
- 객관식과 OX 초안만 생성합니다.
- 문제·선택지·정답·해설·난이도·개념 태그를 반환합니다.
- 숫자 정답과 복수정답 가능성을 시스템이 검사합니다.
- 파일·시험지 업로드와 단답형·서술형 생성은 MVP에서 제외합니다.
- AI 문제는 `REVIEW_REQUIRED`에서 시작하고 교사 승인 전 공개하지 않습니다.

## 7. 투자 뉴스와 그래프

- 투자 MVP에서 AI는 기업·업종·재무정보를 생성하지 않습니다. 가상 자산 4종의 이름과 심볼은 교사 또는 검증된 제품 데이터가 제공합니다.
- 가격 경로는 시드가 고정된 규칙 기반 시나리오가 생성합니다.
- 앱은 실제 과거 가격 이력만 선 그래프로 표시합니다.
- AI는 정해진 시나리오 버전의 자산·가격 단계에 연결된 가상 뉴스와 설명만 만듭니다.
- 시장을 열기 전에 단계별 뉴스를 생성하고 교사가 검토·수정·승인합니다.
- 학생 API는 현재 공개 단계까지의 가격과 승인된 뉴스만 반환하며 미래 가격 단계와 미공개 뉴스를 노출하지 않습니다.
- AI 미래 예측 가격·예측선과 실제 종목 추천은 제공하지 않습니다.

## 8. 기술·안전

- AI 모듈: Python + FastAPI + Pydantic
- 기본 공급자: AWS Bedrock
- 대체 공급자: 관리자가 허용한 경우의 OpenAI 어댑터
- 배포: AWS 서울 리전 ECS Fargate

모든 요청에 AI 실행 ID를 부여하고 구조화 출력, 금칙어·유해 콘텐츠·실제 금융조언을 검사합니다. 학급·학교 단위 AI 전체 끄기를 제공합니다.
