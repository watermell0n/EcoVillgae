# 이코빌리지 API 공통 규칙

- 버전: v0.4
- 기준일: 2026-07-29
- 상태: 공통 계약 확정
- 범위: 학생·교사용 앱, 교사·관리자 웹, 핵심 API, AI 내부 API, 실시간 연결

이 문서는 개별 HTTP 엔드포인트와 WebSocket 이벤트를 작성할 때 공통으로 적용할 계약입니다. 제품 정책은 [API 명세 전 결정사항](API_PRE_DESIGN_DECISIONS.md), 권한은 [역할·권한 매트릭스](PERMISSION_MATRIX.md), 상태 전이는 [핵심 상태 머신](STATE_MACHINES.md), 화면 행동은 [화면 ID·행동 명세](SCREEN_SPEC.md)를 우선합니다.

## 1. 설계 원칙

| ID | 확정 규칙 |
| --- | --- |
| API-CMN-001 | 핵심 API 서버가 인증·권한·금액·상태 전이의 최종 결정자다. |
| API-CMN-002 | 클라이언트가 보낸 역할·가격·세율·잔액·합계·현재 상태는 신뢰하지 않고 서버에서 다시 계산한다. |
| API-CMN-003 | 모든 변경 명령은 적용할 `UIA-*`, `PM-*`, 필요한 `SM-*` ID를 명세에 연결한다. |
| API-CMN-004 | 금액·아이템·금융상품 변경은 원장과 하나의 트랜잭션으로 확정하고 커밋 이후에만 이벤트를 발행한다. |
| API-CMN-005 | 완료 거래는 수정·삭제하지 않으며 원거래를 참조하는 복구 거래로 정정한다. |
| API-CMN-006 | AI는 설명과 초안만 반환하고 데이터베이스·학생 계좌·정책을 직접 변경하지 않는다. |
| API-CMN-007 | 공용 화면은 별도 공개 DTO만 사용하며 내부 DTO를 필드 마스킹해서 재사용하지 않는다. |
| API-CMN-008 | 오프라인 변경 명령은 지원하지 않는다. 재연결 후 서버 상태를 조회하고 사용자가 다시 확정한다. |

## 2. 프로토콜과 버전

- 외부 API 기본 경로는 `/api/v1`입니다.
- HTTPS와 UTF-8 JSON을 사용하고 필드명은 `snake_case`, 열거형은 `UPPER_SNAKE_CASE`를 사용합니다.
- 외부 ID는 의미를 추측할 수 없는 문자열 UUID를 사용하고 데이터베이스 순번을 노출하지 않습니다.
- URL은 복수형 리소스 명사를 사용하고 학급 리소스는 `/api/v1/classrooms/{classroom_id}/...` 아래에 둡니다.
- 조회는 `GET`, 생성과 실행 명령은 `POST`, 전체 설정 교체는 `PUT`, 일부 설정 변경은 `PATCH`를 사용합니다.
- `DELETE`는 세션, 미게시 초안처럼 실제 삭제가 허용된 리소스에만 사용합니다. 완료 거래·원장·상태 이력에는 사용하지 않습니다.
- 하위 호환 가능한 필드 추가는 v1 안에서 허용합니다. 필드 삭제·의미 변경·필수값 추가는 새 API 버전에서 처리합니다.
- OpenAPI 3.1 문서를 HTTP 계약의 기준으로 사용하며 운영 환경의 문서 UI는 인증된 교직원·운영자에게만 공개합니다.

## 3. 인증과 세션

### 3.1 학생 앱

- 학생은 학급 코드·출석번호·닉네임·비밀번호로 로그인하며 실명을 요구하지 않습니다.
- 학급 코드는 서버가 `ABCDEFGHJKMNPQRSTUVWXYZ23456789` 문자 집합에서 8자를 암호학적으로 안전하게 임의 생성합니다. 전역 유일 제약 충돌 시 새 코드로 최대 5회 재시도하고, 모두 실패하면 `CLASSROOM_CODE_GENERATION_FAILED`를 반환합니다. 생성 후에는 변경하지 않습니다.
- 로그인 입력의 학급 코드는 앞뒤 공백을 제거하고 영문을 대문자로 정규화한 뒤 정확히 8자인지 검사합니다.
- 앱 액세스 토큰은 짧은 만료시간을 사용하고 갱신 토큰은 Expo SecureStore에만 저장합니다.
- 액세스 토큰 기본 만료는 15분, 갱신 토큰 기본 만료는 14일입니다. 갱신할 때마다 토큰을 회전하고 이전 토큰을 폐기합니다.
- 학생은 한 학급에서 활성 태블릿 세션 1개를 기본으로 합니다. 다른 태블릿에서 로그인하면 기존 학생 세션을 폐기하고 기존 기기는 다음 요청 또는 실시간 알림에서 로그아웃합니다.
- 로그인 실패 횟수로 학생 계정을 잠그지 않습니다. 인프라 보호용 순간 요청 제한은 계정 잠금 상태를 만들지 않으며 짧은 재시도 시각을 응답합니다.

### 3.2 교사·관리자

- 교사용 앱은 Bearer 액세스 토큰과 회전형 갱신 토큰을 사용합니다.
- 교사·관리자 웹은 `HttpOnly`, `Secure`, `SameSite` 쿠키 세션과 CSRF 방어를 사용합니다.
- 교사는 수업 중 앱과 관리 웹을 함께 사용할 수 있으므로 학생의 단일 태블릿 세션 정책을 적용하지 않습니다.
- 비밀번호 재설정은 기존 이코빌리지의 본인 확인 절차를 호출하고 닉네임 재설정 경로는 만들지 않습니다.

### 3.3 내부 서비스

- 핵심 API, AI 서비스와 비동기 작업자는 만료시간·대상 서비스·허용 범위가 포함된 서비스 자격증명을 사용합니다.
- 서비스 자격증명은 사용자 토큰으로 대체하지 않고 AWS Secrets Manager 등 배포 비밀 저장소에서 관리합니다.
- AI 서비스 토큰에는 학생 계좌·원장·정책을 변경하는 범위를 발급하지 않습니다.

## 4. 권한 판정

서버는 다음 순서로 매 요청을 판정합니다.

1. 사용자 또는 서비스 인증
2. 역할 확인
3. 학교·학급 소속 범위 확인
4. 리소스 소유권과 대상 학생 확인
5. 경제교실·학생 앱 모드·모듈 상태 확인
6. 명령별 OWN·COT·승인 권한 확인
7. 정책 버전·한도·상태 버전 확인
8. 실행 또는 거부 결과 감사 기록

- 토큰의 사용자 식별자와 서버의 최신 학급 역할을 함께 사용합니다.
- `classroom_id`, `screen_id`, `ui_action_id`와 클라이언트가 보낸 역할은 권한 증명이 아닙니다.
- 다른 학교나 미담당 학급의 리소스 존재 여부가 노출될 수 있으면 `403` 대신 `404`를 반환합니다.
- 학생 개인 금융·신용·평가 결과는 본인과 담당 OWN·COT만 조회할 수 있습니다.
- SAD는 학교 운영 집계와 사유가 있는 감사 범위, POP는 서비스 운영 메타데이터만 조회합니다.

## 5. 요청 공통 계약

### 5.1 헤더

| 헤더 | 적용 | 규칙 |
| --- | --- | --- |
| `Authorization` | 앱·내부 서비스 | `Bearer {token}` |
| `X-Refresh-Token` | 앱 토큰 갱신 | `API-AUTH-004`에서만 SecureStore의 회전형 갱신 토큰 전송, 로그 마스킹 |
| `Idempotency-Key` | 모든 변경 명령 | 클라이언트가 사용자 행동마다 생성한 UUID, 화면의 `request_id`와 같은 값 |
| `X-Correlation-Id` | 모든 요청 | 분산 추적 ID, 없으면 게이트웨이가 생성 |
| `Accept-Language` | 선택 | 기본 `ko-KR`, 화면 메시지 언어 선택 |
| `Content-Type` | 본문 요청 | `application/json` |

### 5.2 명령 본문 컨텍스트

```json
{
  "expected_state_version": 12,
  "screen_id": "SCR-STU-017",
  "ui_action_id": "UIA-FIN-009",
  "client_occurred_at": "2026-07-29T05:30:15.120Z"
}
```

- `expected_state_version`은 상태를 바꾸는 명령과 정책 수정에 필수입니다.
- `screen_id`와 `ui_action_id`는 추적·분석용이며 권한 판정 근거로 사용하지 않습니다.
- `client_occurred_at`은 진단용입니다. 마감·이자·가격·순위 계산에는 서버 접수 시각을 사용합니다.
- 학급 범위는 가능한 한 경로의 `classroom_id`로 표현하고 본문에 중복 입력하지 않습니다.
- 가격·세금·합계·현재 잔액은 서버가 상품·정책 스냅샷과 원장에서 계산합니다.

## 6. 멱등성과 동시성

### 6.1 멱등성

- 모든 `POST`, `PUT`, `PATCH`, `DELETE` 변경 명령에 `Idempotency-Key`가 필요합니다.
- 서버는 `실행자 + HTTP 메서드 + 정규화 경로 + Idempotency-Key`를 기준으로 처리 결과를 저장합니다.
- 같은 키와 같은 요청 본문을 재시도하면 최초의 HTTP 상태와 응답 본문을 그대로 반환합니다.
- 같은 키를 다른 본문에 재사용하면 `409 IDEMPOTENCY_KEY_REUSED`를 반환합니다.
- 거래·금융·승인 명령의 멱등성 결과는 해당 업무 기록 보존기간과 함께 보존합니다. 일반 설정 명령은 최소 24시간 보존합니다.
- 네트워크 오류 후 클라이언트는 새 키로 재실행하지 않고 같은 키로 결과를 확인합니다.

### 6.2 낙관적 동시성

- 상태 보유 리소스는 증가하는 정수 `state_version`을 응답합니다.
- 상태 변경 명령은 마지막으로 읽은 `expected_state_version`을 보냅니다.
- 버전이 다르면 변경하지 않고 `409 STATE_VERSION_CONFLICT`와 최신 상태·버전을 반환합니다.
- 클라이언트는 최신 가격·잔액·재고·상태를 표시하고 사용자의 재확인을 받아 새 요청 키로 다시 요청합니다.
- 승인·결제·가입·상환 직전에는 권한, 상태, 잔액, 재고, 한도와 정책을 같은 트랜잭션 안에서 다시 검증합니다.

## 7. 성공 응답

모든 성공 응답은 `data`와 `meta`를 사용합니다.

```json
{
  "data": {
    "order_id": "0b0d5f76-2a1f-4dbe-b0cd-bfc63eae9e13",
    "status": "COMPLETED",
    "state_version": 3
  },
  "meta": {
    "request_id": "efdf1dd1-08ca-41af-8a79-096ba1b195d6",
    "correlation_id": "51e91363-8170-43fe-aa24-81593b89c8e7",
    "server_time": "2026-07-29T05:30:15.248Z"
  }
}
```

| HTTP 상태 | 용도 |
| --- | --- |
| `200 OK` | 조회·수정·동기 명령 성공 |
| `201 Created` | 새 리소스 생성 |
| `202 Accepted` | AI 생성·내보내기·종료 정산 등 비동기 작업 접수 |
| `204 No Content` | 세션·연결 해제처럼 본문이 필요 없는 성공 |

- `202` 응답에는 `operation_id`, `status_url`, `status`를 포함합니다.
- 생성 응답에는 `Location` 헤더를 제공합니다.
- 명령 결과에는 변경된 리소스의 최신 `status`와 `state_version`을 가능한 한 포함합니다.
- 실시간 화면의 HTTP snapshot 응답은 `meta.event_sequence`를 포함해 이후 WebSocket 이벤트 적용 기준을 제공합니다.

## 8. 오류 응답

```json
{
  "error": {
    "code": "STATE_VERSION_CONFLICT",
    "message": "상태가 변경되었습니다. 최신 내용을 확인해 주세요.",
    "retryable": false,
    "details": [
      {
        "field": "expected_state_version",
        "reason": "STALE",
        "current_value": 13
      }
    ]
  },
  "meta": {
    "request_id": "efdf1dd1-08ca-41af-8a79-096ba1b195d6",
    "correlation_id": "51e91363-8170-43fe-aa24-81593b89c8e7",
    "server_time": "2026-07-29T05:30:15.248Z"
  }
}
```

- 클라이언트는 `message` 문자열이 아니라 `code`로 분기합니다.
- 입력값 오류의 `details`에는 안전한 필드명과 사유만 포함하고 내부 예외·SQL·토큰을 노출하지 않습니다.
- 부분 성공은 사용하지 않습니다. 일괄 작업은 항목별 사전 검증 결과를 보여준 뒤 전체 실행 또는 명시적인 항목별 명령으로 분리합니다.

### 8.1 공통 HTTP 상태와 코드

| HTTP | 대표 코드 |
| --- | --- |
| `400` | `VALIDATION_ERROR`, `MALFORMED_JSON`, `IDEMPOTENCY_KEY_REQUIRED` |
| `401` | `AUTH_REQUIRED`, `TOKEN_EXPIRED`, `SESSION_REVOKED` |
| `403` | `ROLE_NOT_ALLOWED`, `OWNER_REQUIRED`, `RESOURCE_NOT_OWNED`, `APP_MODE_BLOCKED`, `MODULE_NOT_ACTIVE`, `PUBLIC_DATA_ONLY`, `AI_DIRECT_WRITE_FORBIDDEN`, `SERVICE_SCOPE_VIOLATION` |
| `404` | `RESOURCE_NOT_FOUND` 또는 범위 밖 리소스 |
| `409` | `STATE_VERSION_CONFLICT`, `POLICY_VERSION_CONFLICT`, `INVALID_STATE_TRANSITION`, `APPROVAL_REQUIRED`, `CLASS_NOT_ACTIVE`, `IDEMPOTENCY_KEY_REUSED`, `DUPLICATE_RESOURCE` |
| `422` | `INSUFFICIENT_BALANCE`, `OUT_OF_STOCK`, `LIMIT_EXCEEDED`, `POLICY_VIOLATION` |
| `429` | `RATE_LIMITED`, `AI_DAILY_LIMIT_EXCEEDED` |
| `500` | `INTERNAL_ERROR` |
| `503` | `DEPENDENCY_UNAVAILABLE`, `ASYNC_QUEUE_UNAVAILABLE` |
| `504` | `AI_TIMEOUT` |

오류 발생 시 금액·아이템·상태는 변경되지 않아야 합니다. 이미 커밋된 완료 거래의 운영 오류는 오류 응답으로 과거를 수정하지 않고 복구 거래를 생성합니다.

권한 판정 내부의 `CLASS_NOT_ASSIGNED`는 다른 학급의 존재를 숨기기 위해 외부 응답에서 `404 RESOURCE_NOT_FOUND`로 변환합니다.

## 9. 목록·검색·내보내기

- 일반 목록은 커서 페이지네이션을 사용합니다.
- 기본 `limit`은 20, 최대는 100입니다.
- 응답 `meta.page`에는 `next_cursor`와 `has_more`를 포함합니다.
- 기본 정렬은 `created_at DESC, id DESC`처럼 유일하고 안정적인 보조 키를 사용합니다.
- 기간 필터는 `from` 이상, `to` 미만의 반개방 구간을 사용합니다.
- 허용된 필터·정렬 필드만 명세하고 임의 필드 검색은 허용하지 않습니다.
- `total_count`는 비용이 필요한 값이므로 기본 목록에는 포함하지 않고 리포트 화면에서 명시적으로 요청한 경우만 제공합니다.
- 대용량 PDF·CSV 내보내기는 `202` 비동기 작업으로 접수하고 완료 후 만료되는 서명 URL을 제공합니다.

페이지 응답 예시:

```json
{
  "data": [],
  "meta": {
    "request_id": "a39f423a-3a3a-47e4-835d-b4c22bcedd69",
    "correlation_id": "29642fa4-fbaf-4c71-b8b9-0b4e8b07ea10",
    "server_time": "2026-07-29T05:30:15.248Z",
    "page": {
      "next_cursor": null,
      "has_more": false
    }
  }
}
```

## 10. 시간·금액·비율

- API 시각은 UTC ISO 8601 밀리초와 `Z`를 사용합니다.
- 학급에는 IANA 시간대 문자열을 저장하며 대한민국 기본값은 `Asia/Seoul`입니다.
- 반복 일정 입력은 학급 현지 시각과 시간대를 받고 서버가 UTC 실행 시각으로 변환합니다.
- 자동 납입·상환·만기·종료 판정은 서버 시각을 기준으로 합니다.
- 학급 화폐는 최소 단위 정수 `amount`로 전달하고 부동소수점 금액을 사용하지 않습니다.
- 수량은 양의 정수이며 원장 증감액만 부호 있는 정수를 사용합니다.
- 세율·금리·등락률은 정수 `rate_bps`로 전달합니다. `100`은 1%, `10000`은 100%입니다.
- 계산은 서버 `BigDecimal`로 수행하고 최소 화폐 단위 변환은 `HALF_UP`을 기본으로 합니다.
- 상품은 `단가 × 수량`을 먼저 계산한 뒤 세금을 한 번 계산하며, 적용 정책과 반올림 방식은 정책 스냅샷에 남깁니다.
- 표시용 문자열은 서버 계산값을 바꾸지 않으며 클라이언트가 학년 난이도와 언어에 맞게 포맷합니다.
- `currency_name`은 OWN이 경제교실 생성 요청에 반드시 포함합니다.
- 서버는 Unicode NFKC 정규화와 앞뒤 공백 제거 후 `^[가-힣A-Za-z0-9]{1,10}$` 형식과 서비스 금칙어 목록을 검사합니다.
- 공백·문장부호·이모지·제어문자는 허용하지 않습니다. 금칙어는 욕설·혐오·성적 표현·서비스 운영자 오인 명칭을 포함하고, 정규화한 값에 대해 영문 대소문자를 구분하지 않고 포함 일치로 검사합니다.
- 생성 후에는 학급 화폐 단위명을 바꾸는 API를 제공하지 않습니다. 금액은 계속 정수 `amount`로 저장하고 단위명은 표시 메타데이터로만 사용합니다.

## 11. 비동기 작업과 AI

- AI 생성, 리포트 내보내기, 대규모 정산은 공통 작업 리소스를 사용합니다.
- 작업 상태는 `QUEUED → RUNNING → SUCCEEDED | FAILED | CANCELED`입니다.
- 같은 멱등성 키의 작업 재요청은 기존 `operation_id`를 반환합니다.
- AI 요청은 핵심 API가 권한·집계·최소 입력을 검증한 후 AI 서비스에 전달합니다.
- AI 서비스는 구조화된 초안과 근거만 반환하고 핵심 API가 Pydantic·도메인 규칙으로 다시 검증합니다.
- AI 20초 제한과 자동 재시도 1회 이후에는 `AI_TIMEOUT` 또는 `DEPENDENCY_UNAVAILABLE`을 반환하고 수동 운영 경로를 유지합니다.
- 교사 승인 명령은 AI 실행 명령과 분리하고 승인 시점의 최신 정책·상태를 다시 검증합니다.

## 12. 실시간 연결 공통 경계

상세 채널과 이벤트는 [WebSocket 명세](WEBSOCKET_SPEC.md)에서 정의하며 다음 규칙을 고정합니다.

- HTTP 트랜잭션 커밋 전에는 실시간 성공 이벤트를 발행하지 않습니다.
- 연결용 토큰은 짧은 만료시간·단일 목적·학급·활동 범위로 발급하고 URL 쿼리에 장기 액세스 토큰을 넣지 않습니다.
- 이벤트에는 `event_id`, `event_type`, `occurred_at`, `classroom_id`, `resource_id`, `state_version`을 포함합니다.
- 전달은 중복될 수 있으므로 클라이언트는 `event_id`로 중복 제거합니다.
- 연결이 끊기면 제출 성공을 추정하지 않고 HTTP 조회로 서버 접수 결과와 최신 상태를 확인합니다.
- 공용 화면 토큰은 공개 DTO 채널만 구독할 수 있고 연결 해제·활동 종료 시 즉시 폐기합니다.

## 13. 감사·로그·개인정보

- 권한 매트릭스의 필수 감사 대상은 성공과 실패를 모두 기록합니다.
- 감사 기록에는 실행자, 당시 역할, 대상, `PM-*`, `UIA-*`, 전후 상태, 사유, 멱등성 키, 상관관계 ID와 서버 시각을 남깁니다.
- 비밀번호, 액세스·갱신 토큰, 서비스 자격증명, AI 원문과 불필요한 학생 개인정보는 로그에 남기지 않습니다.
- 애플리케이션 로그의 학생 식별자는 내부 식별자 또는 가명값을 사용합니다.
- 공개 DTO에는 개인 잔액·신용·대출·TEST 결과·개인거래 상세를 포함하지 않습니다.
- 오류 응답과 관측 도구에서는 학급 간 데이터와 인증정보가 노출되지 않도록 필드 필터를 적용합니다.

## 14. 개별 API 명세 필수 열

각 HTTP API는 최소한 다음 항목을 가져야 합니다.

| 항목 | 내용 |
| --- | --- |
| API ID | `API-{영역}-{3자리 번호}` |
| 화면 행동 | 연결된 `UIA-*`, 조회 전용이면 `SCR-*` |
| HTTP | 메서드와 경로 |
| 실행자·범위 | STU·OWN·COT·SAD·POP·SYS와 SELF·학급·학교 범위 |
| 권한 | 적용 `PM-*` |
| 상태 | 적용 `SM-*`, 허용 현재 상태와 결과 상태 |
| 입력·출력 | 요청·응답 스키마와 필드 마스킹 |
| 멱등성·동시성 | 키 필요 여부와 `expected_state_version` |
| 오류 | 가능한 공통·도메인 오류 코드 |
| 감사 | 성공·실패 기록 여부와 필수 사유 |
| 요구사항 | 연결된 RTM 요구사항 ID |

WebSocket 이벤트는 `EVT-{영역}-{3자리 번호}`, 채널은 `WS-{영역}-{3자리 번호}`를 사용합니다.
