# 이코빌리지 학년×규모 추천 코스

- 확정일: 2026-07-29
- 상태: MVP 추천 데이터 기준

## 1. 적용 원칙

- `1회·1주·1달·1학기`는 실제 날짜나 회차를 고정하지 않는 추천 규모 라벨입니다.
- 실제 운영기간과 활동 횟수는 교사가 자유롭게 정합니다.
- 아래 표의 모든 모듈은 **추천**이며 필수 선택 모듈은 없습니다. 역할(직업)·급여도 교사가 선택하며, 선택하지 않으면 학생은 직업과 급여 없이 다른 선택 모듈만 이용합니다.
- 1회 코스는 퀴즈·게임만 기본 추천하지만 라벨만으로 다른 모듈을 금지하지 않습니다. 교사가 금액 모듈을 선택하면 실제 운영기간·일정·예산을 검증합니다.
- 모든 경제교실은 개설 시 학급 화폐 단위명을 필수로 저장합니다. 금액 모듈이 없으면 단위명을 금액 화면에 사용하지 않습니다.
- 금액을 사용하는 모듈을 선택하면 지갑·거래원장을 기술 인프라로 자동 준비합니다. 지갑·거래원장은 교사가 선택해야 하는 별도 필수 모듈이 아닙니다.
- 금융 기본 추천은 초4 `정기예금`, 초5 `정기예금·정기적금`, 초6 `정기예금·정기적금·가상 투자`입니다.
- 대출은 초5 1학기와 초6 1학기에만 기본 추천합니다.
- 실제 상품 상점은 교사 운영 부담 때문에 항상 선택 모듈입니다.
- AI 챗봇과 AI 경제 밸런싱은 코스 선택 모듈이 아닌 교사 공통 운영 기능입니다.

## 4. 추천 데이터 필드

추천표는 AI 결과가 아니라 버전 관리되는 제품 데이터입니다.

- 학년과 규모 라벨
- 핵심·선택 모듈
- 추천 이유와 학습목표
- 선수개념과 조건부 선행 관계
- 난이도 프로필
- 제외 시 사라지는 학습 흐름
- 추천 데이터 버전과 적용일

선택하지 않은 모듈은 학생 앱에서 숨깁니다.
