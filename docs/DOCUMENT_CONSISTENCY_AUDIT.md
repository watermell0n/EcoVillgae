## 3. 의도적으로 유지한 차이

- 실제 상품 상점은 MVP 기능이지만 모든 코스에서 선택 모듈입니다.
- 교사는 학년 기본 추천에 없는 모듈을 추가할 수 있으며 해당 학년 난이도 프로필을 적용합니다.
- 학생·교사용 앱과 관리자·교사 관리 웹은 기능이 겹칠 수 있지만 같은 권한 정책과 API를 사용합니다.
- AI는 조정값을 제안할 수 있지만 교사 승인 없이 적용하지 않습니다.
- `1회`는 추천 규모 중 하나지만 경제 원장·금융상품을 만들지 않는 별도 경량 흐름입니다.
