# 이코빌리지 MVP 이후 추가 모듈 및 발전 방향

- 기준일: 2026-07-29
- 상태: MVP 이후 후보

이 문서의 기능은 MVP 일정과 구현을 약속하지 않습니다. 정기예금·정기적금·가상 투자·교육용 대출은 이미 MVP 범위이므로 후보 목록에서 제외합니다.

## 1. 대상 확장

### 1.1 중학생 코스

- 중1: 심화 예산관리, 보험, 장기 대출·신용
- 중2: 학생 운영 상점, 생산·재고·원가·매출·이익
- 중3: 심화 투자·위험관리, 주거·청약과 자산 리포트

초등 코스의 문장만 어렵게 바꾸지 않고 계산 난이도, 책임, 거래 구조와 리포트를 재설계합니다.

### 1.2 코스 고도화

- 교사 코스 저장·복제와 검증된 코스 공유
- 학교·지역 일정 템플릿
- 접근성과 읽기 수준별 검증 콘텐츠
- 충분한 운영 데이터가 쌓인 뒤의 추천 개선

AI가 코스를 임의로 생성하는 기능은 별도 검증 후 판단합니다.

## 2. 추가 경제 모듈

### 2.1 금융·생활

| 후보 | 목표 | 선수개념 |
| --- | --- | --- |
| 보험 | 위험 이전, 보험료와 보장 | 위험, 예산 |
| 독립형 신용관리 고도화 | 장기 신용등급, 연체 영향과 회복 | MVP 대출·상환 기록 |
| 금융사기 예방 | 피싱·사칭·안전한 결제 | 디지털 결제, 신용 |
| 주거·청약 | 주거비·임대·목표 저축 | 예산, 대출, 저축 |

### 2.2 시장·상점 운영

| 후보 | 목표 |
| --- | --- |
| 시장가격·물가 심화 | 수요·공급, 구매력과 인플레이션 |
| 생산·재고 | 생산량, 재고 부족과 보관 비용 |
| 원가·매출·이익 | 판매가격, 비용, 매출과 이익 구분 |
| 학생 운영 상점 | 역할 분담, 가격 결정, 판매와 결산 |

공식 상점과 학생 운영 상점의 돈 흐름과 권한은 분리합니다.

### 2.3 자리·부동산

자리·부동산은 MVP에서 제외합니다. 향후에는 교실 자리를 일반 상품이 아닌 `기간형 교실 공간 이용권`으로 다룹니다.

- 기본 좌석과 학습권 보장
- 접근성·건강·수업 운영 우선 배정
- 이용기간·만료와 재판매 제한
- 실제 부동산 소유 개념과의 차이 안내

## 3. AI 발전

- AI가 만드는 가상 기업 배경·업종·재무 단서와 다회차 심화 투자 시나리오
- 접근성·읽기 수준 변환과 교사 비교 승인
- 승인된 자료 안에서만 답하는 학생 학습 도우미
- 제한된 상태 머신 기반 경제 역할극 NPC
- 근거가 연결된 교사 보고서
- 장기 학습지도와 복습 추천

가격과 수익률은 앞으로도 AI가 아닌 규칙 기반 시뮬레이터가 결정합니다.
MVP에는 교사·제품 데이터가 정한 가상 자산과 가격 단계에 연결된 뉴스 생성만 포함하며,
기업 자체 생성과 재무 서사는 이 문서의 미래 범위로 남깁니다.

## 4. 플랫폼 발전

- 공동 담당 교사와 학교 관리자 고도화
- 여러 학급을 묶은 학교 운영
- 학급 간 콘텐츠 공유·승인
- 학교별 보관·내보내기·삭제 정책
- 장애 시 읽기 전용·복구 모드
- 학교 MDM과 네트워크 정책 연동

## 5. 승격 기준

후보를 정식 모듈로 승격하려면 다음을 확인합니다.

- 교육·운영 문제가 명확한가
- 기존 모듈로 해결할 수 없는가
- 선수개념과 대상 학년이 정해졌는가
- 돈·아이템·학습 데이터의 이동이 명확한가
- 학생 간 격차와 낙인 위험을 통제할 수 있는가
- 교사가 이해하고 승인할 수 있는가
- 실패·취소·복구와 보관 정책이 정의됐는가
- 측정 가능한 성공 기준과 인수 테스트가 있는가
