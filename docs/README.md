## 협업 원칙

- 작업은 기능 단위로 분리합니다.
- 커밋은 `1 Action, 1 Commit` 원칙을 따릅니다.
- 브랜치는 Git Flow 기반으로 운영합니다.
- PR 생성 전 로컬에서 실행 가능한 테스트와 빌드를 확인합니다.
- 작업 내용, 영향 범위, 관련 이슈를 명확히 공유합니다.
