# 이코빌리지 요구사항 기준선·용어집

- 버전: v0.3
- 기준일: 2026-07-29
- 상태: 요구사항 76개 기준선·역할 권한·화면 용어 반영

## 1. 문서 규칙

- 요구사항 ID는 한 번 발급하면 의미를 바꾸거나 재사용하지 않습니다.
- 요구사항이 폐기되면 ID를 삭제하지 않고 상태를 `RETIRED`로 변경합니다.
- 한 요구사항이 크게 분리되면 기존 ID를 상위 요구사항으로 유지하고 하위 ID를 추가합니다.
- 상세 설계가 아직 없더라도 제품 정책이 확정됐으면 상태를 `BASELINED`로 둡니다.
- `P0`는 MVP 필수, `P1`은 MVP 선택·운영 편의 기능입니다.
