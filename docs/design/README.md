# 캐릭터·디자인 산출물

캐릭터 콘셉트, 실루엣, 색상·스타일, 프로필 상태, 슬롯·레이어와 에셋 파일 규칙을
저장합니다. 실제 바이너리 에셋은 `assets/characters/`에 둡니다.

## 학생 앱 디자인

- [도트 캐릭터 이미지 작업 규격](CHARACTER_ASSET_SPEC.md): **에셋 제작·검수 정본.**
  64×64 단일 캔버스, 좌표·대칭 규칙, 팔레트, 레이어 순서, 가림 마스크, 파일명, 자동 검사
- 캐릭터는 단일 체형이며 모든 상품을 64×64 투명 PNG 레이어로 관리합니다. 웹과 Expo가
  같은 에셋을 참조합니다.
- [FE 통합 디자인 가이드](FE_DESIGN_GUIDE.md): FE 라벨 Jira 이슈를 한곳에 모은 화면 생성 기준, IA, 상태·개인정보·컴포넌트 규칙
- [FE 화면 생성 상세 스펙](FE_SCREEN_GENERATION_SPEC.md): 화면별 레이아웃, 색상, 필요 데이터, 상태, 금지 규칙
- [학생 앱 디자인 페이지](STUDENT_DESIGN_PAGE.md): 학생 화면 생성용 페이지 구조, 디자인 토큰, 공통 컴포넌트, 화면별 디자인 구상
- [학생 앱 디자인 HTML](student-design-page.html): 학생 화면 생성 기준을 시각화한 브라우저용 보드
