# 이전 픽셀 백엔드 구현 참고본

이 디렉터리는 기존 `release` 작업 트리에서 진행했던 캐릭터 코스메틱 백엔드 구현을 보존한 참고본이다.

현재 `develop` 기반 백엔드는 `com.b201.ecovillage` 패키지와 새 도메인 구조를 사용하지만, 이전 구현은 `com.b201.bibim` 패키지를 기준으로 작성되어 그대로 빌드 경로에 넣으면 충돌한다. 그래서 아래 내용을 컴파일 대상과 분리해 보존했다.

- 캐릭터·코스메틱 엔티티와 저장소
- 캐릭터 조회·구매·착용 서비스 및 DTO
- 캐릭터 API 컨트롤러
- V30~V32 코스메틱 테이블·슬롯·시드 마이그레이션
- 기존 서비스 테스트

새 백엔드에 적용할 때는 이 참고본의 구매 멱등성, 소유권, 슬롯, 체형, 시드 규칙을 현재 원장·상점 도메인에 맞춰 이식한다.
