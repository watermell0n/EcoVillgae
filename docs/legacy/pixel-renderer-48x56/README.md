# 48×56 절차적 렌더러 (참고 자료)

`pixelRenderer.ts`는 2026-08-05 이전 학생 앱 웹에서 쓰던 코드형 도트 렌더러다.
48×56 논리 캔버스에 정수 좌표 도트를 직접 그렸고, 카탈로그 64종 전부의 형태를 담고 있었다.

**앱에서는 더 이상 쓰지 않는다.** 이유:

- 논리 캔버스를 64×64로 통일했다 ([규격](../../design/CHARACTER_ASSET_SPEC.md))
- 48→64 변환은 비정수 배율이라 도트가 깨진다
- 웹에만 있어서 Expo와 같은 상품이 다르게 보였다
- 캔버스 폭 48이 하드코딩되어 있다 (`mirrorRows`의 `47 - right`)

## 왜 지우지 않고 남기는가

**규격 §11 3·4단계에서 만들 상품 54종의 유일한 형태 참고 자료다.**
각 상품의 실루엣 행 좌표, 팔레트, 세부 배치가 여기에 있다. 64×64 에셋을 만들 때
이 좌표를 기준으로 옮겨 그린다(48→64이므로 단순 배율 변환이 아니라 재작화다).

54종 에셋이 모두 배포되어 `PENDING_ASSET_KEYS`가 비면 이 디렉터리를 삭제한다.

## 주의: 팔레트가 다르다

이 파일의 상수는 현재 팔레트와 값이 다르다. 색을 그대로 가져오지 말고
[규격 §4](../../design/CHARACTER_ASSET_SPEC.md)의 값을 쓴다.

```
이 파일          현재 정본
INK   #273038 → #262b31
CHEEK #f3a6b8 → #f1a3b5
WHITE #fffdf8 → #fffdf8 (동일)
```

## 좌표 변환 시 유의

48×56 좌표를 64×64로 옮길 때 `× 4/3`은 정수가 아니다. 규격 §3.1의 실측 실루엣과
§3.4의 앵커 표를 기준으로 **다시 배치**한다. 특히 아래는 좌표를 그대로 쓰면 안 된다.

- 배낭이 `x2..10` / `x38..46`에 그려져 몸에 가려졌다 → 규격 §9.1
- 공룡 꼬리가 몸에 거의 다 가려졌다 → 규격 §9.2
- 목도리가 배 높이 `y26..32`에 있었다 → 규격 §9.6
