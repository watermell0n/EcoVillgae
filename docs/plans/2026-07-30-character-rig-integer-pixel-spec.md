## 핵심 원칙

옷을 체형에 맞춰 스케일하지 않는다. 체형이 달라져도 슬롯 부착점은 움직이지 않는다.

논리 캔버스와 머리 크기는 고정하고, 몸통 폭만 좌우 대칭을 유지하는 짝수 픽셀 간격으로 바꾼다. 비정수 스케일, 회전, 실시간 메시 워핑은 허용하지 않는다.

## 체형 티어

| 코드 | 표시명 | 몸통 폭 |
| --- | --- | ---: |
| `CHUBBY` | 포근 | 21px |
| `BASE` | 기본 | 17px |
| `SLIM` | 산뜻 | 13px |
| `VERY_SLIM` | 가벼움 | 11px |

티어는 되돌릴 수 있으며, 자동 전환에는 진입값과 이탈값이 다른 히스테리시스를 적용한다.

## 슬롯과 레이어

렌더 순서는 배경 → 발밑 → 등 → 꼬리 → 기본 몸 → 몸통 → 얼굴 → 왼손 → 오른손 → 머리 → 이펙트다.

머리, 얼굴, 목, 어깨, 손, 발, 발밑, 등, 꼬리, 이펙트 앵커는 `src/character-rig.json`의 정수 좌표를 단일 기준으로 사용한다. 개별 아이템 오프셋은 이미지에 굽지 않고 메타데이터로 관리한다.

후드와 투구는 머리 슬롯을 점유하며 필요한 경우 얼굴·머리 오클루전 마스크를 적용한다. 전신 몸통 아이템은 하의와 상호 배제한다.

## 몸통 에셋 전략

1. 티어별 수작업: 일반 의상은 각 체형에 맞는 별도 몸통 에셋을 사용한다.
2. 정수 9슬라이스: 로브·갑옷·패딩처럼 넓은 의상은 좌우 고정 영역과 중앙 반복 띠로 나눈다.

누락된 티어 에셋은 가장 가까운 체형 티어로 폴백하고 QA 경고를 남긴다.

파일명은 `slot_itemid_tier_frame.png` 형식을 사용한다. 예: `torso_wizardrobe_t2_00.png`.

## 렌더링

- 원본은 1배율 PNG, 알파는 0 또는 255만 사용
- 외곽선 1px, 제한 팔레트, 좌상단 단일 광원
- 화면 배율은 정수만 허용
- nearest-neighbor, 밉맵 off, 안티에일리어싱 off
- 모든 스프라이트 위치와 피벗을 정수 디바이스 픽셀에 스냅
- 프리뷰와 인게임은 동일한 합성 렌더러 사용

## QA

상점 하단의 자동 QA 매트릭스는 전체 77개 아이템을 4개 체형에 합성한 308개 조합을 보여준다. GPU 최대 캔버스 크기를 넘지 않도록 12개 아이템씩 7페이지로 나눈다.

출시 전 확인 항목:

- 네 체형을 겹쳤을 때 머리·얼굴·어깨·손·발 앵커가 일치
- 공통 머리 에셋이 모든 체형에서 같은 크기와 위치
- 몸통 에셋에 반투명 픽셀과 비정수 변형이 없음
- 슬롯 충돌과 오클루전 규칙이 조합 프리뷰에서도 동일
- 누락 에셋 폴백 경고가 0개
