# 학생용 페이지 구상

- 기준 문서: `docs/SCREEN_SPEC.md`, `docs/REQUIREMENTS_BASELINE.md`
- 기준 Jira: `S15P11B201-190` ~ `S15P11B201-196`
- 스타일 기준: Figma 캡처의 파스텔 마을 UI
- 기준 해상도: 1280x800 학생 태블릿

## 1. 스타일 방향

학생 앱은 관리형 대시보드가 아니라, 아이들이 경제 활동 공간을 돌아다니는 `마을 앱`처럼 보여야 한다.

- 상단: 짙은 개발 메뉴 또는 앱 바, 그 아래 하늘색-민트색 헤더
- 배경: 하늘색에서 민트, 연노랑으로 흐르는 부드러운 그라데이션
- 홈: 기능을 표처럼 나열하지 않고 `이코 상점`, `이코 은행`, `투자 광장` 같은 큰 마을 카드로 진입
- 상세 화면: 중앙 제목과 설명을 먼저 보여주고, 큰 카드 1~2개로 핵심 상태를 표현
- 정보량: 학생 화면은 짧은 문장 위주. 긴 정책 문구는 접힌 도움말이나 보조 카드로 분리
- 캐릭터: 실제 도트 캐릭터 에셋을 그대로 올릴 수 있게 캐릭터 영역은 이미지 슬롯 중심으로 유지
- 금액: 모든 학생 금액 표기는 `비빔`
- 개인정보: 개인 잔액, 금융, 평가 결과는 본인 화면에서만 표시하고 공용 화면에는 노출하지 않음

## 2. 공통 레이아웃

### 2.1 상단 구조

```text
개발 메뉴 / 화면 그룹 탭
이코빌리지 로고 | 현재 위치 pill | 1일차 | 보유 비빔 | 학생
```

- 현재 위치 pill 예: `마을 광장`, `월급명세서`, `선생님 수업`, `투자 결과`
- 오른쪽 상태 pill: `1일차`, `135비빔`, `학생`
- 선생님 수업 또는 GUIDED 상태에서는 자유 활동 메뉴를 잠그고 수업 화면을 우선 표시

### 2.2 화면 상태

| 상태 | UI 처리 |
| --- | --- |
| `AUTONOMOUS` | 마을 카드 진입 가능, 활성 모듈만 표시 |
| `GUIDED` | 선생님 수업 화면 고정, 상점·거래·금융 잠금 |
| `CLOSED` | 조회 중심. 구매·거래·가입 버튼 비활성화 |
| `READ_ONLY` | 최종 리포트·기록만 조회 |
| 오프라인 | 변경 버튼 비활성화, 마지막 조회값 안내 |

## 3. 홈 정보구조

`SCR-STU-003 경제교실 홈·상태 안내`는 학생 앱의 중심이다.

### 3.1 마을 카드

| 카드 | 연결 화면 | 표시 조건 | 카드 문구 |
| --- | --- | --- | --- |
| 이코 상점 | `SCR-STU-006` | 상점 ACTIVE | 상품을 사요 |
| 이코 은행 | `SCR-STU-013` 또는 `SCR-STU-014` | 예금·적금 중 하나 이상 활성 | 예금 가입 가능 |
| 투자 광장 | `SCR-STU-016` | 투자 모듈 활성 | 투자 가능 |
| 월급명세서 | `SCR-STU-005` | 급여 사용 코스 | 내 급여 확인 |
| 마을 회의 | `SCR-STU-012` | 공동기금 또는 투표 LIVE | 공동기금 투표 |
| 투자 결과 | `SCR-STU-018` | 투자 모듈 활성 | 결과 공개 |
| 이코 주택관 | MVP 이후 | 비활성 또는 NEW | 청약으로 내 집 마련 |
| 이코 보험사 | MVP 이후 | 비활성 또는 NEW | 준비물·숙제 보험 |
| 이코 신용센터 | `SCR-STU-019`, `SCR-STU-020` | 대출 모듈 활성 | 대출·신용점수 |

### 3.2 카드 상태

- `입장하기`: 현재 학생이 진입 가능
- `수업 후 열려요`: GUIDED 중이거나 교사가 닫은 모듈
- `공사중`: MVP 제외 또는 아직 비활성
- `NEW`: 새로 열린 모듈
- `결과 공개`: 학생이 변경하지 않고 조회만 하는 화면

## 5. 최신 문서 반영으로 추가해야 할 화면

Jira `190~196`은 21개 화면 단위였지만, 최신 `SCREEN_SPEC.md`는 학생 화면을 24개로 정리했다. 따라서 Figma/프로토타입에서는 아래 3개를 별도 화면으로 보강한다.

| 화면 ID | 화면 | 구상 |
| --- | --- | --- |
| `SCR-STU-002` | 비밀번호 재설정 | 로그인과 같은 배경, 비밀번호만 재설정. 닉네임 재설정 없음 |
| `SCR-STU-013` | 금융 홈 | 이코 은행 안에서 예금·적금·투자·대출 모듈 카드 진입 |
| `SCR-STU-024` | 개인·최종 리포트 | READ_ONLY 후 30일 조회 가능. 잔액·금융·학습 결과 요약 |

## 7. 프로토타입 반영 원칙

- 현재 `student-tablet-prototype.html`은 화면 ID 확인용으로 24개 화면을 유지한다.
- 홈과 월급명세서부터 Figma 캡처 스타일을 우선 적용한다.
- 나머지 화면은 같은 컴포넌트 문법으로 점진적으로 치환한다.
- 도트 캐릭터는 직접 그리지 않고 `assets/characters/exports` 이미지가 들어갈 슬롯만 설계한다.
- 버튼은 성공을 추정하지 않고 “처리 중”, “재시도”, “최신 상태 다시 불러오기” 상태를 가진다.
