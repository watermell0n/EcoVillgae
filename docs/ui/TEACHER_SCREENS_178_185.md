## 0. 공통 화면 규칙

### 0.1 교사 화면 톤

- 학생 화면보다 정보 밀도는 높게, 시각 분위기는 부드럽게 유지한다.
- 배경은 연한 하늘/마을 톤을 쓰되, 실제 작업 영역은 흰색 패널로 정리한다.
- 주요 액션은 하늘색/민트 계열, 위험 액션은 붉은 계열로 제한한다.
- 모든 화면은 `상단 상태 바 + 좌측 메뉴 + 중앙 작업 영역 + 우측 요약 패널`을 기본 구조로 삼는다.
- 교실 생성, 추천 코스처럼 단계형 작업은 좌측 메뉴 대신 상단 stepper를 사용한다.

### 0.2 공통 컴포넌트

| 컴포넌트 | 사용 위치 | 규칙 |
| --- | --- | --- |
| Top Status Bar | 로그인 이후 전체 | 교실명, 운영 상태, 공용 화면 연결, 알림, 계정 |
| Left Nav | 교실 내부 화면 | 대시보드, 운영 센터, 학생 관리, 경제 관리, 상점, 금융, 퀴즈, 리포트, 설정 |
| Stepper | 개설/추천/설정 흐름 | 현재 단계와 완료 단계를 명확히 표시 |
| Right Summary Panel | 저장/승인/검토 화면 | 변경 내용, 위험 경고, 다음 액션 |
| Status Chip | 목록/표/카드 | 운영 중, 임시 저장, 승인 대기, 연결됨, 잠김 |
| Confirm Modal | 돈 이동/승인/개설 | 최종 확인과 영향 범위 표시 |
| Empty State | 목록이 비었을 때 | 다음 행동 버튼을 반드시 포함 |

T-178-03_Classroom_Empty
T-179-01_Classroom_Basic_Info

## 1. S15P11B201-178 교사 로그인·경제교실 선택 화면 3종

### T-178-01 교사 로그인

목적: 교사가 서비스에 진입하고 경제교실 목록으로 이동한다.

레이아웃:

- 전체 배경: 파스텔 마을 배경
- 중앙 패널: 로고, 서비스명 `이코빌리지`, 설명 문구
- 입력 영역: 아이디/이메일, 비밀번호
- 주요 버튼: `교사로 로그인`
- 보조 링크: 비밀번호 찾기, 처음 사용하는 교사 안내

핵심 액션:

- 로그인 성공: `T-178-02_Classroom_Select`
- 로그인 실패: 입력 필드 아래 오류 문구
- 비밀번호 찾기: 별도 모달 또는 외부 인증 흐름

상태/예외:

- Empty: 입력 전 버튼 비활성화
- Loading: 버튼 `로그인 중...`, 입력 잠금
- Failed: `계정 정보가 맞지 않아요. 다시 확인해주세요.`

### T-178-02 경제교실 목록·선택

목적: 교사가 운영할 경제교실을 선택한다.

레이아웃:

- 상단 상태 바: 계정, 알림
- 중앙 제목: `내 경제교실`
- 교실 카드 목록: 교실명, 학년/반, 운영 기간, 학생 수, 운영 상태
- 우측 또는 상단 버튼: `새 경제교실 만들기`

핵심 액션:

- 교실 카드 클릭: `T-182-01_Class_Economy_Status`
- 새 경제교실 만들기: `T-179-01_Classroom_Basic_Info`
- 임시 저장 교실 클릭: 마지막 작성 단계로 이동

상태/예외:

- Loading: 교실 카드 스켈레톤
- Empty: `T-178-03_Classroom_Empty`
- Error: 목록 재시도 버튼

### T-178-03 경제교실 미생성 빈 상태

목적: 교실이 없는 교사에게 첫 개설 행동을 안내한다.

레이아웃:

- 중앙 큰 일러스트: 빈 마을 또는 새 집
- 안내 문구: `아직 만든 경제교실이 없어요`
- 설명: `우리 반 경제생활을 시작하려면 경제교실을 먼저 만들어주세요.`
- 주요 버튼: `경제교실 만들기`
- 보조 버튼: `샘플 교실 둘러보기`

핵심 액션:

- 경제교실 만들기: `T-179-01_Classroom_Basic_Info`
- 샘플 교실 둘러보기: 읽기 전용 데모 대시보드

상태/예외:

- 권한 없음: 관리자 또는 팀원에게 문의 안내

## 2. S15P11B201-179 교사 경제교실 개설 화면 3종

### T-179-01 경제교실 기본 정보 입력

목적: 교실 이름과 기본 학급 정보를 설정한다.

레이아웃:

- 상단 stepper: 기본 정보 > 기간 설정 > 개설 완료
- 중앙 폼 패널
- 우측 요약 패널: 현재 입력값 미리보기

입력 항목:

- 교실 이름
- 학교명
- 학년
- 반
- 수업 대상 설명
- 화폐명 기본값

핵심 액션:

- 다음: `T-179-02_Classroom_Period`
- 임시 저장: 목록으로 돌아가되 임시 저장 카드 생성

상태/예외:

- 교실 이름 없음: 다음 버튼 비활성화
- 이름 중복: `이미 사용 중인 교실 이름이에요.`

### T-179-02 학년·운영기간 설정

목적: 교실 운영 기간과 운영 유형을 정한다.

레이아웃:

- 좌측: 운영 유형 카드 4개
- 중앙: 시작일/종료일, 활동 요일, 하루 활동 시간
- 우측: 추천 모듈 경고 및 요약

운영 유형:

- 1회 체험
- 1주 프로젝트
- 1달 운영
- 1학기 운영

핵심 액션:

- 이전: `T-179-01_Classroom_Basic_Info`
- 개설하기: `T-179-03_Classroom_Created`

상태/예외:

- 종료일이 시작일보다 빠름: 오류 표시
- 짧은 기간에 예금/공공 예산 선택 예정: 경고 칩 표시

### T-179-03 개설 완료·초기 안내

목적: 교실 개설 완료 후 다음 행동을 안내한다.

레이아웃:

- 중앙 완료 패널: 체크 아이콘, `경제교실이 열렸어요`
- 학생 접속 QR/링크 영역
- 다음 할 일 카드 3개
- 우측 요약: 교실명, 기간, 학생 수, 켜진 모듈

다음 할 일:

- 학생 명단 등록하기
- 추천 코스 고르기
- 대시보드로 이동하기

핵심 액션:

- 학생 등록: `T-183-03_Student_Account_Reset`
- 추천 코스: `T-180-01_Recommend_Conditions`
- 대시보드: `T-182-01_Class_Economy_Status`

## 3. S15P11B201-180 교사 코스 추천 화면 3종

### T-180-01 추천 조건 입력

목적: 교사가 학급 상황에 맞는 운영 코스 추천 조건을 입력한다.

레이아웃:

- 상단 stepper: 조건 입력 > 추천 결과 > 이유 상세
- 좌측: 질문 카드 목록
- 우측: 선택 요약

입력 항목:

- 운영 기간
- 학년
- 학생 수
- 수업 목표: 소비/저축/세금/공공재/거래
- 난이도
- 사용하고 싶은 모듈

핵심 액션:

- 추천 보기: `T-180-02_Recommend_Result`
- 초기화: 입력값 리셋

상태/예외:

- 필수 조건 부족: 추천 버튼 비활성화
- 추천 불가 조합: 대체 조건 제안

### T-180-02 추천 코스 결과

목적: 추천 코스 후보를 비교하고 하나를 선택한다.

레이아웃:

- 중앙: 추천 코스 카드 3개
- 각 카드: 코스명, 기간, 핵심 모듈, 난이도, 예상 활동 수
- 우측: 선택한 코스 요약

핵심 액션:

- 코스 선택: 카드 강조
- 추천 이유 보기: `T-180-03_Recommend_Reason`
- 이 코스로 시작: `T-181-01_Module_Select`

상태/예외:

- 추천 결과 없음: 조건 수정 안내
- 로딩: 코스 카드 스켈레톤

### T-180-03 추천 이유 상세

목적: 왜 이 코스가 추천되었는지 교사가 이해하게 한다.

레이아웃:

- 상단: 코스명, 적합도
- 중앙: 추천 이유 목록
- 하단: 포함 모듈 타임라인
- 우측: 적용 시 변경되는 설정 요약

핵심 액션:

- 선택하기: `T-181-01_Module_Select`
- 다른 추천 보기: `T-180-02_Recommend_Result`

주의:

- 추천은 AI 자동 생성이 아니라 제품이 가진 추천 테이블 기반으로 표현한다.
- AI처럼 단정하는 문구보다 `이런 반에 잘 맞아요` 톤을 사용한다.

## 4. S15P11B201-181 교사 모듈·일정 설정 화면 3종

### T-181-01 추천 모듈 선택

목적: 사용할 경제 모듈을 선택하고 학생 메뉴 구성을 결정한다.

레이아웃:

- 중앙: 모듈 카드 그리드
- 카드 정보: 모듈명, 설명, 권장 여부, 학생 노출 여부
- 우측: 켜진 모듈 요약과 의존성 경고

모듈:

- 지갑
- 월급
- 세금
- 상점
- 캐릭터
- 개인 거래
- 예금
- 공공 예산/투표
- 퀴즈
- AI 운영 보조

핵심 액션:

- 모듈 토글
- 다음: `T-181-02_Schedule_Edit`

상태/예외:

- 개인 거래 ON + 승인 정책 없음: 경고
- 예금 ON + 운영 기간 짧음: 경고

### T-181-02 운영 일정 편집

목적: 모듈별 운영 일정을 조정한다.

레이아웃:

- 중앙: 주/일 단위 일정표
- 좌측: 모듈 필터
- 우측: 선택한 날짜의 활동 목록

핵심 액션:

- 활동 추가
- 일정 이동
- 활동 잠금/열기
- 다음: `T-181-03_Autonomous_Modules`

상태/예외:

- 일정 충돌: 충돌 칩 표시
- 수업 종료 이후 활동: 저장 불가

### T-181-03 자율 이용 모듈 허용 설정

목적: 학생이 교사 개입 없이 사용할 수 있는 모듈을 정한다.

레이아웃:

- 중앙: 모듈별 자율 이용 권한 표
- 열: 학생 노출, 자율 이용, 교사 승인 필요, 시간 제한
- 우측: 학생 화면 미리보기

핵심 액션:

- 권한 토글
- 학생 화면 미리보기
- 저장 후 대시보드 이동

상태/예외:

- 돈 이동 모듈 자율 허용 시 확인 모달
- 승인 필요 모듈은 학생에게 `승인 대기` 상태가 있음을 안내

## 5. S15P11B201-182 교사 대시보드 화면 3종

### T-182-01 학급 경제 현황

목적: 교사가 오늘의 경제 상태를 한눈에 본다.

레이아웃:

- 상단 상태 바: 교실명, 운영 상태, 공용 화면 연결
- KPI 카드: 총 화폐량, 평균 잔액, 공공기금, 참여 학생 수
- 중앙: 최근 경제 활동 타임라인
- 우측: 오늘 해야 할 일

핵심 액션:

- 활동 시작: 운영 센터
- 장부 보기: 경제 관리
- 리포트 보기: 리포트

상태/예외:

- 데이터 없음: 개설 직후 안내
- 이상 분포: 위험 알림으로 연결

### T-182-02 위험·운영 알림

목적: 교사가 놓치면 안 되는 운영 이슈를 확인한다.

레이아웃:

- 중앙: 알림 목록
- 필터: 전체, 경제, 학생, 거래, 일정, 시스템
- 우측: 선택한 알림 상세와 처리 버튼

알림 예시:

- 승인 대기 거래
- 잔액 부족 학생 다수
- 제출률 낮음
- 공용 화면 연결 끊김
- 일정 충돌

핵심 액션:

- 알림 처리
- 관련 화면으로 이동
- 나중에 보기

### T-182-03 오늘 활동 빠른 실행

목적: 교사가 수업 중 자주 쓰는 활동을 빠르게 시작한다.

레이아웃:

- 중앙: 빠른 실행 카드
- 카드: 월급 지급, 세금 징수, 퀴즈 시작, 투표 시작, 상점 열기
- 우측: 공용 화면 연결 상태와 참여 준비 상태

핵심 액션:

- 활동 시작
- 예약 활동 실행
- 공용 화면 열기

상태/예외:

- 공용 화면 미연결: 연결 안내
- 학생 접속 부족: 시작 전 경고

## 6. S15P11B201-183 교사 학생 관리 화면 3종

### T-183-01 학생 목록

목적: 전체 학생 계정과 접속 상태를 관리한다.

레이아웃:

- 중앙: 학생 표
- 열: 출석번호, 이름, 닉네임, 접속 상태, 잔액, 최근 활동, 조치
- 상단: 검색, 상태 필터, 학생 추가
- 우측: 선택 학생 요약

핵심 액션:

- 학생 상세 보기: `T-183-02_Student_Detail`
- 학생 추가/초기화: `T-183-03_Student_Account_Reset`
- 일괄 선택

개인정보 원칙:

- 교사 화면에서는 학생 식별 정보가 필요하므로 표시한다.
- 공용 화면으로 노출되는 데이터와 구분한다.

### T-183-02 학생 상세·개인 기록

목적: 한 학생의 참여와 경제 기록을 확인한다.

레이아웃:

- 상단: 학생 기본 정보
- KPI: 잔액, 누적 수입, 누적 지출, 참여율
- 탭: 거래 내역, 활동 기록, 보상/벌금, 계정 정보
- 우측: 교사 조치

핵심 액션:

- 보상 지급
- 벌금/차감
- 비밀번호 초기화
- 거래 내역 상세 확인

상태/예외:

- 돈 이동 조치는 확인 모달 필수
- 민감 정보는 복사/노출보다 초기화 중심으로 처리

### T-183-03 계정 등록·비밀번호 초기화

목적: 학생 계정을 만들거나 접속 문제를 해결한다.

레이아웃:

- 탭: 직접 등록, CSV 업로드, 비밀번호 초기화
- 중앙: 입력 폼 또는 업로드 영역
- 우측: 적용될 학생 수와 경고

핵심 액션:

- 학생 등록
- CSV 검증
- 초기 비밀번호 발급
- QR/접속 안내 출력

상태/예외:

- 중복 출석번호: 오류 행 표시
- CSV 형식 오류: 샘플 양식 안내

## 7. S15P11B201-184 교사 급여·세금 설정 화면 3종

### T-184-01 역할별 월급 설정

목적: 학생 역할 또는 기본 기준에 따라 월급을 설정한다.

레이아웃:

- 중앙: 역할별 월급 표
- 열: 역할명, 지급액, 지급 주기, 자동/수동, 적용 학생 수
- 우측: 월급 지급 요약과 예상 총액

핵심 액션:

- 역할 추가
- 지급액 수정
- 지급 주기 선택
- 저장

상태/예외:

- 지급액 0 이하: 오류
- 총 지급액이 과도함: 경고

### T-184-02 소득세·부가세 정책 설정

목적: 학급 경제에서 적용할 세금 규칙을 정한다.

레이아웃:

- 중앙: 세금 정책 카드
- 카드: 소득세, 소비세/부가세, 벌금, 공공기금 적립
- 우측: 정책 적용 예시

핵심 액션:

- 세금 ON/OFF
- 고정세/비율세 선택
- 세율 입력
- 저장

상태/예외:

- 세율 100% 초과: 저장 불가
- 세금 OFF 시 관련 화면 숨김 안내

### T-184-03 월급명세서 미리보기

목적: 학생에게 보일 월급/세금 결과를 사전에 확인한다.

레이아웃:

- 중앙: 학생용 명세서 미리보기
- 좌측: 샘플 학생 선택
- 우측: 지급 전 확인 요약

명세서 항목:

- 기본 월급
- 보너스
- 세금
- 최종 지급액
- 지급 예정일

핵심 액션:

- 미리보기 학생 변경
- 월급 지급 실행
- 설정으로 돌아가기

상태/예외:

- 지급 실행 전 확인 모달
- 이미 지급한 기간이면 중복 지급 경고

## 8. S15P11B201-185 교사 상점·거래 승인 화면 3종

### T-185-01 상품·재고 목록

목적: 학생이 구매할 수 있는 상품과 재고를 관리한다.

레이아웃:

- 중앙: 상품 표 또는 카드형 목록
- 열: 상품명, 가격, 재고, 판매 상태, 구매 승인 필요, 조치
- 상단: 상품 추가, 검색, 상태 필터
- 우측: 선택 상품 요약

핵심 액션:

- 상품 등록: `T-185-02_Product_Edit`
- 판매 상태 변경
- 재고 수정
- 구매 내역 보기

상태/예외:

- 상품 없음: 첫 상품 등록 안내
- 품절: 상태 칩과 학생 화면 노출 방식 안내

### T-185-02 상품 등록·수정

목적: 상품 정보를 만들거나 수정한다.

레이아웃:

- 중앙 폼: 상품명, 설명, 가격, 재고, 이미지, 판매 기간
- 옵션: 구매 승인 필요, 1인 구매 제한, 환불 가능 여부
- 우측: 학생 화면 상품 카드 미리보기

핵심 액션:

- 저장
- 미리보기
- 판매 시작/중지

상태/예외:

- 가격 0 이하: 오류
- 재고 없음 + 판매 중: 경고
- 이미지 없음: 기본 아이콘 사용

### T-185-03 개인거래 검토·승인

목적: 학생 간 개인 거래 요청을 검토하고 승인/반려한다.

레이아웃:

- 중앙: 승인 대기 거래 목록
- 열: 요청자, 상대 학생, 품목/금액, 요청 시간, 위험 표시, 조치
- 우측: 선택 거래 상세와 승인/반려 버튼

핵심 액션:

- 승인
- 반려
- 학생 기록 보기
- 거래 정책 수정

상태/예외:

- 승인 대기 없음: 빈 상태와 최근 처리 내역
- 잔액 부족으로 승인 불가: 버튼 비활성화와 사유 표시
- 의심 거래: 위험 알림 칩
- 승인/반려 후 학생 화면에는 결과 알림 표시
