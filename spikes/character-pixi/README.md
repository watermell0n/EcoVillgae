# Character PixiJS spike

React와 PixiJS로 4개 체형과 77개 코스메틱의 페이퍼돌 합성을 검증하는 독립 스파이크입니다.

## 실행

```bash
npm install
npm run dev
```

## 픽셀 리그 원칙

- 논리 캔버스는 `28 × 32`, 도트 셀은 `5px`, 화면 배율은 정수 `×2`입니다.
- 체형은 스케일하지 않고 몸통 폭만 짝수 픽셀 간격으로 변경합니다.
- 머리, 얼굴, 어깨, 손, 발 앵커는 모든 체형에서 같은 좌표를 사용합니다.
- 머리 아이템은 체형 공통 에셋을 사용합니다.
- 몸통 아이템은 티어별 수작업 또는 중앙 띠 정수 반복 방식만 사용합니다.
- 렌더러는 nearest-neighbor, 정수 좌표, 안티에일리어싱 비활성화를 강제합니다.

## 구현 범위

- 체형: `CHUBBY`, `BASE`, `SLIM`, `VERY_SLIM`
- 중립 체형명: 포근, 기본, 산뜻, 가벼움
- 슬롯: 배경, 이펙트, 등·꼬리, 하의, 신발, 몸통, 목 장식, 얼굴, 손 소품, 머리
- 상호 배제: 전신 몸통 아이템과 하의 등 충돌 슬롯 자동 해제
- 체형 전환: 가역 히스테리시스 적용
- 에셋 메타데이터: `src/character-rig.json`
- 자동 QA: 77개 아이템 × 4개 체형, 308개 조합을 7페이지로 렌더링

프로덕션 제작 규칙은 `docs/plans/2026-07-30-character-rig-integer-pixel-spec.md`를 기준으로 합니다.
