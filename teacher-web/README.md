# 교사 관리 웹·교실 공용 화면

Next.js App Router와 TypeScript를 사용하는 교사 관리 웹 작업 영역입니다.

## 소유 범위

- 경제교실 개설·학생·코스·모듈·정책 관리
- 거래 승인·퀴즈 제작·AI 운영 지원·리포트
- 교사가 수업 중 학생에게 보여주는 공용 화면

## 경계

- 교사용 화면과 공용 화면의 공개 데이터 모델을 분리합니다.
- 공용 화면에는 학생 개인 잔액·금융·평가 결과를 표시하지 않습니다.
- API 접근 권한은 화면이 아니라 핵심 API가 최종 판단합니다.

초기 Next.js 프로젝트는 이 디렉터리 안에서만 생성하고 루트 공통 설정을 임의로 변경하지 않습니다.
